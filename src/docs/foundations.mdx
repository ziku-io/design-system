# Foundations

What every Ziku app shares before it renders a single component. All of it ships
in `@ziku/ui/styles.css` and the package itself; an app adds nothing to get it.

## Type

**Geist** for text and **Geist Mono** for code, self-hosted through
`@fontsource-variable/geist` and `@fontsource-variable/geist-mono`, both
dependencies of this package. `styles.css` imports them. No Google Fonts link,
no `@font-face` in the app. The system stacks sit behind them in `--font-sans`
and `--font-mono` for the moment before the files arrive.

Use `font-mono` for IDs, amounts in a ledger, keyboard keys. Numbers that sit
in prose or a tile stay in the sans with `tabular-nums`.

Weights in use: 400, 500 (controls: buttons, toggles, tabs, badges), 600
(titles). Nothing bolder: 700 next to 600 reads
as a mistake, not a hierarchy.

## Icons

**Phosphor only**, `@phosphor-icons/react`, imported with the `*Icon` names
(`HouseIcon`, not `House`). Never Lucide or Heroicons.

- **Weight:** `regular`. `fill` only to mark a selected state against its own
  regular twin (a starred item, the active tab icon). No `duotone`, no `bold`.
- **Size** follows the text it sits next to, set with a class, not the `size`
  prop:
  - `size-3.5` (14px) beside `text-xs`: chips, filter pills, badges. Nothing
    smaller; a filled dot (a radio's indicator) is a mark, not an icon.
  - `size-4` (16px) inline with `text-sm`, in buttons, menus, the command
    palette, table cells, tiles. Buttons and menu items apply it already.
  - `size-6` inside `EmptyState`'s circle and on a status screen. Nothing
    larger in product UI.
- **Muted** is `text-muted-foreground`, never `opacity-*`.
- **Colour:** inherits `currentColor`. A decorative icon beside a label is
  `text-muted-foreground`. An icon that is the only content of a button needs
  an `aria-label` from the dictionary; one beside text gets `aria-hidden`.
- Blocks take icons as the component, `icon={WalletIcon}`, so they can size it.

## Colour

Colours are CSS variables in `src/styles/globals.css`. Tailwind utilities read
them: `bg-primary`, `text-muted-foreground`, `border-danger-border`. Every
swatch and ratio on this page is read from the live stylesheet, so it cannot
drift from the CSS.

The rules that matter day to day:

- The palette is soft: text is a dark gray, not black, and every colour is
  kept below OKLCH chroma 0.12. Do not reach for a stronger colour to add
  emphasis; use weight or size.
- Never write a hex value in an app. If a colour is missing, it belongs in
  `globals.css`, with its contrast measured.
- `primary` is a fill for small marks. Inline links are `text-link`.
- Status text is `text-{status}-fg`, never the fill.
- Selected is `bg-accent`, everywhere: a menu row, a toggle, a table row, the
  sidebar's active item.
- Motion that brings something in uses `ease-settle`.

### Charts

Five series colours, `chart-1` to `chart-5`, taken in order. A bar carries no
label of its own, so these are measured for separation rather than contrast
alone: a worst pairwise ΔE of 24.9 across normal vision, protanopia,
deuteranopia and tritanopia, every series at least 3:1 on a card and the page,
and lightness staggered so they stay apart in greyscale. Never pick one by eye.

### Categorical slots

Five colours that mean nothing, for things an app has to tell apart without any
of them being good or bad: a service line, a project type, a team, a tag.

They are a third set on purpose. A status colour carries meaning, and a
service line tinted danger red says the service line is broken. The chart set
is built for a filled bar with no label, a 3:1 problem. A slot is text on a
tint, a 4.5:1 problem: `text-slot-2` on `bg-slot-2-subtle`.

Every slot clears 4.5:1 on its own tint, the page and a card, the five hold a
worst pairwise ΔE of 20.9 under all four kinds of vision, and every hue sits at
least 25° off the status hues and the brand.

sections, `gap-5` between form fields, `gap-2` between inline controls, `p-4`
inside a panel.

## Language

Every word a component renders comes from one typed dictionary. Wrap the app
once:

```tsx
import { ptPT, UIStringsProvider } from "@ziku/ui"

<UIStringsProvider strings={ptPT}>{app}</UIStringsProvider>
```

- `ptPT` is complete European Portuguese. English is the default when nothing
  is wrapped.
- An app can override any subset on top: `strings={{ ...ptPT, auth: { ...ptPT.auth, signIn: "Entrar" } }}`.
- Numbers, percentages and dates inside the dictionary are formatted for its
  locale, so `StatTile`'s `change` and `ActivityList`'s times follow the language.
- A component that renders a word not in the dictionary fails
  `no-literal-strings.test.ts`. That covers `blocks/` and `components/ui/`.

## States

Every block that shows fetched data takes the same three props, so a page
wires a query to any of them the same way:

```tsx
<DashboardPanel title="Recent activity" loading={q.isPending} error={q.isError} onRetry={q.refetch}>
  <ActivityList items={q.data} />
</DashboardPanel>
```

- `loading` wins over `error`, which wins over content. A retry in flight is
  loading, so the error band does not sit there while the request runs.
- `error={true}` says the dictionary's sentence; a string says its own.
- The block keeps its outline while it loads: a tile keeps its label, a board
  its declared columns, a table its headers. Only the data is a placeholder.
- Empty and failed are different states. A list that never arrived is never
  drawn as a list with nothing in it.

`StatTile` takes no `onRetry`: a tile is too small for a button, so the panel
or page that fetched the row carries it. `DataTable`, `Kanban`,
`DashboardPanel` and `ActivityList` take all three; `Combobox` takes `loading`.

## Overriding per app

Redefine any variable after importing the stylesheet. Keep the replacement under
the same contrast: `palette.test.ts` only measures the library's own values.

```css
@import "@ziku/ui/styles.css";
:root { --primary: #3f6fb0; --ring: #3f6fb0; --link: #355f99; }
```

## Enforced

`src/design-rules.test.ts` reads every block and primitive and fails on a
bold, duotone or numerically sized icon, an icon under `size-3.5`,
`font-bold`, a `dark:` class, raw `black`/`white` utilities, `text-primary`
used as text, and a focus ring other than 1.5px at 80%. `palette.test.ts`
measures every colour pair on this page.
