# Design tokens

Colours are CSS variables in `src/styles/globals.css`. Tailwind utilities read
them: `bg-primary`, `text-muted-foreground`, `border-danger-border`.

Every value on this page is read from the live stylesheet, so it cannot drift
from the CSS — and it follows the **theme switcher in the toolbar**. Flip it to
see the other half of the palette.

**Dark is the default.** An app that sets no class on `<html>` renders dark. Add
`class="light"` to opt out. `class="dark"` also works, so `next-themes` with
`attribute="class"` behaves normally in both directions.

Links use `text-link`, never `text-primary`: the fill is tuned for white text on
top of it, the link colour for reading against the page. A link inside a
sentence also needs `underline underline-offset-4` — colour alone fails
WCAG 1.4.1.

## Status

Four states, each with four jobs. Every pairing clears 4.5:1 in both themes; the
numbers were measured, not guessed.

`info`, `warning` and `danger` carry the same four. Two things worth knowing:

- **`--warning-foreground` is dark, not white.** White on any usable amber tops
  out around 3:1. Every other status fill takes white.
- **Never use the fill as text.** `text-danger` is 3.8:1 on a dark card and
  fails. That is exactly what `--danger-fg` is for.

`--destructive` is kept as an alias of `--danger` so upstream shadcn snippets
keep working. New code should say `danger`.

## Charts

Five hues for series, tuned apart from the badge colours above. A bar carries no
label of its own, so these are measured for separation rather than for contrast
alone: worst pairwise ΔE 36.0 dark and 28.4 light, across normal vision and
protanopia, deuteranopia and tritanopia, with the lightness staggered so the
series stay apart in greyscale. Slot 5 is a red, for a series that means
something went wrong. Never pick one by eye; `palette.test.ts` measures them.

## Radius

Flat: 6px on controls and boxes (`rounded-md`, `rounded-lg`), 4px small, 8px for
the largest surfaces.

## Typography

System stack (`-apple-system, BlinkMacSystemFont, "Segoe UI", "Noto Sans",
Helvetica, Arial`), mono is `ui-monospace, SFMono-Regular, "SF Mono", Menlo,
Consolas`. Page titles `text-2xl font-semibold tracking-tight`, body `text-sm`,
helper text `text-sm text-muted-foreground`.

## Spacing rules of thumb

- Page content padding: `p-6`
- Gap between page sections: `gap-6`
- Gap between form fields: `gap-5`
- Gap between inline controls: `gap-2`

## Overriding per app

Redefine any variable after importing the stylesheet:

```css
@import "@ziku/ui/styles.css";
:root { --primary: #0969da; --ring: #0969da; --link: #79c0ff; }
```
