# Design tokens

Colors follow [GitHub Primer](https://primer.style/foundations/primitives/color). Values live as CSS variables in `src/styles/globals.css`; Tailwind utilities read them (`bg-primary`, `text-muted-foreground`, `border-border`).

**Dark is the default.** An app that sets no class on `<html>` renders dark. Add `class="light"` to opt out. `class="dark"` also works, so `next-themes` with `attribute="class"` behaves normally in both directions.

## Two interactive colors

GitHub uses green for the primary action and blue for links and focus. So does this system: `--primary` is green, `--link` and `--ring` are blue. Use `text-link` for inline links, never `text-primary`. Links sitting inside a sentence also need `underline underline-offset-4` — colour alone fails WCAG 1.4.1, and the a11y addon will flag it.

## Radius

Flat, like GitHub: 6px on controls and boxes (`rounded-md`, `rounded-lg`), 4px small, 8px for the largest surfaces. This overrides the shadcn 8/12px scale.

## Typography

The GitHub system stack (`-apple-system, BlinkMacSystemFont, "Segoe UI", "Noto Sans", Helvetica, Arial`), mono is `ui-monospace, SFMono-Regular, "SF Mono", Menlo, Consolas`. Page titles `text-2xl font-semibold tracking-tight`, body `text-sm`, helper text `text-sm text-muted-foreground`.

## Spacing rules of thumb

- Page content padding: `p-6`
- Gap between page sections: `gap-6`
- Gap between form fields: `gap-5`
- Gap between inline controls: `gap-2`

## Overriding per app

Redefine any variable after importing the stylesheet:

```css
@import "@ziku/ui/styles.css";
:root { --primary: #8250df; }
```
