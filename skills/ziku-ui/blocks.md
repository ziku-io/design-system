# Which block for which job

Find the job, take the block, then read its props in
`node_modules/@ziku/ui/dist/index.d.ts`. Primitives (Button, Card, Input,
Select, Tabs, Dialog, DropdownMenu, Popover, Tooltip, Table…) are shadcn's API
with Ziku tokens, so upstream shadcn docs apply to them.

## Conventions every data block shares

- **Async state:** `loading`, `error` (`true` uses the dictionary's sentence, a
  string or node its own), `onRetry`. Loading beats error beats content. A
  block keeps its outline while loading: headers, labels, declared columns.
- **Empty and failed are different states.** Data that never arrived is
  `ErrorState`, never an empty list. `ActivityList items={undefined}` means
  loading or error; `[]` means empty.
- **Writes:** the block never mutates `data`. Callbacks (`onSave`, `onAddRow`,
  `onReschedule`, `onDrop`) may return a promise; reject it and the block
  restores the user's input or the item's position. New values return through
  props.

## Page frame

| Job                   | Block                                                        | Notes                                                                                                                                                                                                                                                                     |
| --------------------- | ------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Signed-in layout      | `AppShell`                                                   | `nav: NavGroup[]`, ≤ 7 items per group, every item has an icon, account group and sign-out last. Counts go in `NavItem.badge`. `bleed` for full-width pages.                                                                                                              |
| Page title + actions  | `PageHeader`                                                 | `title`, `description`, `actions`. One per page.                                                                                                                                                                                                                          |
| Home screen           | `Dashboard` + `DashboardPanel` + `StatTile` + `ActivityList` | `stats` takes tiles; panels take `span="half"\|"full"` and the async props. A tile has no retry; its panel does. A tile that filters a table takes `pressed` + `onPressedChange` and is itself the `<button aria-pressed>`; never wrap it in one. `pressed` alone throws. |
| Theme, zoom, language | `PreferencesMenu`                                            | `LanguagePicker` throws when `value` is not in `options`; the app swaps the dictionary.                                                                                                                                                                                   |
| Product name as logo  | `Wordmark`                                                   | Also what `AppShell brand="…"` and `AuthLayout logo="…"` render.                                                                                                                                                                                                          |
| ⌘K palette            | `CommandMenu` + `SearchTrigger`                              | One per app, navigation group first, every item has an icon. Binds ⌘K itself. `onQueryChange` for server results.                                                                                                                                                         |

## States

| Job                      | Block                    | Notes                                                                                                         |
| ------------------------ | ------------------------ | ------------------------------------------------------------------------------------------------------------- |
| Loaded, nothing there    | `EmptyState`             | `icon`, `title`, `description`, one `action`.                                                                 |
| Read failed              | `ErrorState`             | `onRetry`; `variant="panel"\|"alert"`.                                                                        |
| Render crashed           | `ErrorBoundary`          | `resetKeys={[pathname]}` or the fallback outlives navigation. `onError` to report; it reports nothing itself. |
| Short-lived confirmation | `toast` from the package | Past tense: "Invoice sent."                                                                                   |

## Lists and records

| Job                                | Block                                                                   | Notes                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| ---------------------------------- | ----------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Any list of records                | `DataTable`                                                             | `columns`, `data`, `rowId`. `facet` on a column adds filter and group. `viewKey` saves views (none = nothing saved). Board: `renderCard` + a column's `onSet`. Timeline/calendar: `dates` (+ `onReschedule`). `csv` adds export, `onAddRow` an add line, a column's `onEdit(row, value)` in-place cell edit (`editInput` for `inputMode`/`required`; remove = furniture column + `useConfirm`), `pageSize` a pager, `paged` server paging (columns then need `sortKey`/`filterKey`). Over 100 rows it windows itself. |
| Table state in the URL             | `parseListUrl`, `listUrlProps`, `listUrlOf`, `toListUrl`, `sameListUrl` | Owns six params (`LIST_PARAMS`). Parse once, keep the result.                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| Saved views on a server            | `viewsBackend` prop / `useDataTableViews`                               | A failing `list` falls back to browser-stored views.                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| Standalone board                   | `Kanban`                                                                | `columns` (end states as `tile`), `renderCard`, `itemKey`, `onDrop`. Cards have a "move to" menu for touch and keyboard.                                                                                                                                                                                                                                                                                                                                                                                              |
| Gantt / deadlines grid             | `Timeline` / `CalendarView`                                             | `items`, `itemKey`, `start`, `end`, `label`, `onReschedule`. No `end` = milestone.                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| Summary or spec sheet, not records | `Table` primitive                                                       | Add rows with `TableAddRow`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| CSV export                         | `toCsv` + `downloadCsv`                                                 | Handles delimiter, BOM and formula injection.                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |

## Forms and inputs

| Job                                     | Block                                                                                            | Notes                                                                                                                                                                                                                                                     |
| --------------------------------------- | ------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Form fields                             | `Form`, `FormField`, `Input`, `Textarea`, `Select`, `Checkbox`, `RadioGroup`, `Switch`, `Slider` | react-hook-form + zod, already dependencies.                                                                                                                                                                                                              |
| Pick one from a searchable set          | `Combobox`                                                                                       | `label` required. It does not filter; the caller filters on `query`.                                                                                                                                                                                      |
| Pick several from a short fixed set     | `ChipPicker`                                                                                     | No search; long sets belong in a `DataTable` facet.                                                                                                                                                                                                       |
| Date / range                            | `DatePicker` / `DateRangePicker`                                                                 | Controlled; throws if `min > max`. Range has `presets`. `name` posts `YYYY-MM-DD` (range: `name[from]`, `name[to]`); `required` blocks native submit while empty (range needs both ends) and opens the picker.                                            |
| Copy a value (IBAN, reference, API key) | `CopyButton` / `CopyField`                                                                       | `CopyButton value label`: copy icon → check for 2s, announced; a refused clipboard shows a warning. `CopyField` is a `dt`/`dd` row for a `<dl>`, `mono` for codes, `copy={false}` to line up a row with no button. Never hand-roll `navigator.clipboard`. |
| Rename in place                         | `EditableText`                                                                                   | `onSave` gets the trimmed value, only when changed. Blur does not save.                                                                                                                                                                                   |
| Pick files                              | `FileDrop` + `UploadList`                                                                        | Picks only; the app uploads. `maxFiles` is how many are left. `validateFiles` for the same checks outside the zone.                                                                                                                                       |
| Named document checklist                | `UploadSlots`                                                                                    | `slots`, `value` by slot id, `onFile` per file. Download is a plain link to `item.url`; pass `onDownload(slotId, item)` when the URL needs a bearer token (button, pending while it runs, failed message on rejection).                                   |

## Overlays

| Job                                    | Block                                | Notes                                                                                                          |
| -------------------------------------- | ------------------------------------ | -------------------------------------------------------------------------------------------------------------- |
| Focused task over the page             | `Modal`                              | `open`, `onOpenChange`, `title`, `footer`, `size`. Body scrolls, footer stays. Focus lands on the first field. |
| Record detail, long filters, side work | `Drawer`                             | Modal's API plus `side`.                                                                                       |
| Yes/no, or one short value             | `useConfirm()`                       | `confirm({ title, danger })` → `boolean`; `prompt({ label })` → `string \| null`. Needs `ConfirmProvider`.     |
| Small anchored panel                   | `Popover`, `DropdownMenu`, `Tooltip` | Primitives; they cap to the viewport themselves.                                                               |

## Auth

| Job                  | Block                                                              | Notes                                                                                                                                                                                                                                                                                |
| -------------------- | ------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Sign in / up / reset | `AuthLayout` + `LoginForm` / `RegisterForm` / `ForgotPasswordForm` | `onSubmit` async (spinner while it runs), `error` for the server's message. `registerHref`/`forgotPasswordHref`/`loginHref` accept `null` to hide the link when the app has no sign-up or no mailer. `ForgotPasswordForm sent` shows the inbox state. `RegisterForm phone="optional" | "required"`adds a tel field;`consent={<>I accept the <Link …>privacy policy</Link>.</>}`adds a required checkbox (values gain`phone?`, `consent: true`). |
| OAuth buttons        | `SocialButton` in `providers`                                      | google, github, apple, microsoft. The app owns the redirect.                                                                                                                                                                                                                         |

## Public site (before sign-in)

`SiteLayout` wraps the page. `Hero` comes first and owns the `h1`. Every other block sits inside a `Section`, which sets the width, the vertical rhythm and the `h2`, so an app never writes spacing of its own. Page templates: [site.md](site.md).

| Job                          | Block                               | Notes                                                                                                                                                                                                                                                                                                                                   |
| ---------------------------- | ----------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Header, footer, phone menu   | `SiteLayout`                        | `brand`, `nav` (5 at most, throws past that), `currentHref`, `actions`, `footer` (a `SiteFooter`, built once and passed to every page). Floating bar; below `md` the links move into a `Drawer`.                                                                                                                                        |
| Page foot                    | `SiteFooter`                        | `columns` (1 to 4, throws outside), `aside` (the `NewsletterForm` with a line above it), `owner` (copyright), `note` (address). Marks the current page from SiteLayout's `currentHref`. The same element on every page.                                                                                                                 |
| Band of content              | `Section`                           | `title`, `description`, `align`, `width="narrow"` for text, `tone="muted"`, `id` for an anchor.                                                                                                                                                                                                                                         |
| First screen                 | `Hero`                              | `title` (the `h1`), `description`, `actions`, `command` (install line with copy), `media`, `mediaFrame={false}` when the media draws its own surface, `layout="split"` (throws without media), `background`.                                                                                                                            |
| Product picture              | `WindowFrame`                       | A titled app window around real components: a chart, a `Table` of nodes, status badges. `title` (mono), `meta` (a badge).                                                                                                                                                                                                               |
| Shell session                | `Terminal`                          | `title`, `lines: { kind, text }[]` (`command`, `output`, `ok`, `warn`, `error`, `comment`; unknown kinds throw), `play` types it out once in view, whole at once under reduced motion.                                                                                                                                                  |
| Code, commands               | `CodeBlock`                         | `code`, `title`, `prompt` for shell lines (the `$` is not copied; a `\` continuation gets none). Copy button built in.                                                                                                                                                                                                                  |
| Proof in numbers             | `Specs`                             | 2–4 `{ value, unit, label }`. The label says how it was measured.                                                                                                                                                                                                                                                                       |
| What it does                 | `FeatureList`                       | `items: { title, description, icon or media }[]` (every item media or none, or it throws), `columns={2 \| 3}`. With `media` each point sits under a small product fragment; three at most. Media is hidden from screen readers, so nothing in it may be clickable.                                                                      |
| How it works, with pictures  | `FeatureSplit`                      | `rows: { title, description, points, media }[]`, sides alternate. The main body of a technical landing page, one visual per row.                                                                                                                                                                                                        |
| Who uses it, what it runs on | `LogoStrip`                         | Logos or names in `currentColor`: customers, chains, clouds, model families.                                                                                                                                                                                                                                                            |
| A customer in their words    | `Testimonial`                       | `quote`, `name`, `role` (blank throws), `avatar`, `logo`, `metric: { value, label }` shown large beside the quote. One per page.                                                                                                                                                                                                        |
| Newsletter                   | `NewsletterBand` / `NewsletterForm` | Form in `SiteFooter`'s `aside` on every page; `NewsletterBand` (`title`, `description`, `onSubmit`, `error`, `sent`) as an extra band on a landing page, before the questions, or under the blog's posts. `newsletterSchema(t)` on the server.                                                                                          |
| Price                        | `PricingTable`                      | 1–4 `plans`, string `price`, at most one `highlighted` (throws). Plan `id`s are anchors. On the pricing page only, never a landing page.                                                                                                                                                                                                |
| Plans side by side           | `PlanComparison`                    | The same `plans` array plus `groups: { title, rows: { feature, hint, values } }[]`. A value is `true`, `false` or a string; every row needs exactly one per plan id or it throws. Feature column sticks on a phone.                                                                                                                     |
| Questions                    | `Faq`                               | Native `<details>`. `id`s are anchors (lowercase, digits, dashes), unique, or it throws.                                                                                                                                                                                                                                                |
| Read more, elsewhere         | `PageLinks`                         | 2–4 `{ href, title, description }` cards to Architecture, Changelog, Pricing, Docs.                                                                                                                                                                                                                                                     |
| Closing ask                  | `CtaBand`                           | Same verb as the hero's primary button.                                                                                                                                                                                                                                                                                                 |
| Contact page                 | `ContactForm` + `ContactChannels`   | Form: `onSubmit` async, `error`, `sent`, `topics` (2 to 6 `{ value, label, description }` radio cards; values gain `topic`, required and limited to the list). `contactSchema(t, topicValues)` on the server. Channels: `{ icon, label, value, href, note, copy, mono }[]`; mono values (keys, fingerprints) wrap rather than truncate. |
| Terms, privacy               | `LegalPage`                         | `title`, `updated: Date`, `intro`, `sections: { id, title, body }[]`. Numbered contents list.                                                                                                                                                                                                                                           |
| Blog index / post            | `PostList` / `ArticlePage`          | Postmortems, benchmarks, release notes. Body as children, set in `Prose`.                                                                                                                                                                                                                                                               |
| Any long text                | `Prose` / `PROSE`                   | Styles the app's rendered MDX. The library parses nothing.                                                                                                                                                                                                                                                                              |

## Helpers worth knowing

`SectionLabel` / `LABEL_CLASS` (small uppercase label), `cn`, `initials`,
`storageKey` (namespaced localStorage key), `useTheme`, `useZoom`,
`useIsMobile`, `Link` (routes through `LinkProvider`).
